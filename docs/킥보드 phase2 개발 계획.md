# 킥보드 phase2 개발 계획

기준일: 2026-10-16 · 기준 문서: `킥보드 phase2.md`(원페이저, 문서 안에서는 "핵심목표 피라미드 투두 1단계"), `킥보드 phase2.html`(프로토타입) · 브랜치: `todo-phase2`

## 한 줄 요약

phase1 투두 위에 핵심목표·카테고리·시간 비율을 얹어요. 저녁마다 할 일에 쓴 시간을 적고, 정한 비율과 실제 비율이 15%p 이상 벌어지면 피라미드와 주간 마감에서 보여 줘요. 화면과 문구는 프로토타입을 따르고, phase1 데이터는 지우지 않고 이어 써요.

## 검토 결과: 바로 개발 가능한가

**프로토타입 덕분에 화면 다섯 개와 계산이 거의 다 정해졌어요.** 지난 검토의 빈칸 8개 중 5개가 풀렸고, 남은 4개는 2026-10-16에 모두 추천안으로 정했어요. 개발을 시작할 수 있어요.

### 프로토타입으로 풀린 것

| 지난 검토 | 프로토타입이 정한 것 |
| --- | --- |
| B5 주간 완료율 배지 | 메인에서 "진행 중 n%" 배지, 마감 화면의 큰 %와 달성 링 모두 없어요. 날짜별 달성 링은 메인에 남아요. |
| B6 피라미드 생김새 | 위에서 아래로 넓어지는 칸: 핵심목표(좁은 칸) → 주간 목표(그 기간 주마다 한 줄) → 카테고리 카드 2열(이름·시간, 정한/실제 막대, "n% 많음"·"n% 부족"·"괜찮음 (+n%)"·기타는 "비율 없음", 시간 많이 쓴 할 일 2개 + "외 n개") → 한 줄 판정. 위에 기간 탭: "최근 4주"·주별 4개. |
| B7 시간 옮기기안을 고르면 | 비율은 그대로, 안내 문장이 **메인의 이번 주 목표 아래** "시간 계획: …"으로 보여요. 마감 3단계에도 보여요. |
| B8 기타 기준 | 최근 4주 기타 시간이 **2시간 이상**이고 카테고리가 5개 미만이면 권해요. 이름(8자)을 적고 옮길 기타 할 일을 고른 뒤 "승인"/"그대로 두기". 승인하면 새 카테고리는 10%로 시작하고 가장 큰 카테고리에서 10%를 가져와요. |
| B2 일부 (회고 날짜) | 회고 화면 위 날짜 탭 3개: "그제 10/14"·"어제 10/15"·"오늘 10/16". |
| "회고한 날" | 시간이 1분 이상 적힌 날. 주 평균 시간 = 4주 전체 시간 ÷ 그런 날 수 × 7. 회고 저장 표시를 따로 두지 않아요. |
| 회고에서 추가한 일 | 체크된 상태로 들어가요. 시간 기본값 30분. |

### 프로토타입과 원페이저·phase1이 다른 곳 (이렇게 처리해요)

| 무엇 | 차이 | 처리 |
| --- | --- | --- |
| 할 일 수정·삭제, "이번 주로" 버튼 | phase1에 있었는데 프로토타입엔 없어요 | **남겨요.** 프로토타입이 빠뜨린 것으로 보고 phase1 동작 그대로 |
| 카테고리 라벨 누르기 | 원페이저 "눌러 바꿀 수 있어요" | 프로토타입대로 누를 때마다 **다음 카테고리로 돌아가요**(… → 기타 → 첫 번째) |
| 진입 화면 "영역" vs 다른 화면 "카테고리" | 같은 것을 두 말로 불러요 | **"카테고리"로 통일**(2026-10-16 결정). "+ 영역 추가" → "+ 카테고리 추가", 새 카테고리 기본 이름 "새 카테고리" 등 |
| 비율 0% | 원페이저는 언급 없음, 프로토타입은 0% 허용 | 0~100 허용, 합계 100%일 때만 시작 |
| 카테고리 이름 길이 | 원페이저 없음, 프로토타입 8자 | 8자 |
| "최근 4주"의 범위 | 피라미드는 이번 주 포함 4주, 주간 마감은 지난주까지 4주 | 프로토타입 그대로 둘 다 다르게 |
| 마감 1단계 소제목 | 프로토타입 "이번 주 회고 한 줄"인데 내용은 지난주 것 | "지난주 회고 한 줄"로 고쳐요 |
| 비율 조정안 반올림 | 프로토타입은 남는 %를 첫 카테고리에 몰아줘요 | 옛 Duno의 최대 나머지 방식으로 고르게 나눠요 |
| 실제 비율 반올림 | 프로토타입은 줄마다 반올림해서 합이 99·101%가 될 수 있어요 | 최대 나머지 방식으로 합 100%에 맞춰요 |
| 시간 옮기기안이 0분 | 프로토타입은 "주 0분 줄이기"가 나올 수 있어요 | 30분 미만은 안내하지 않아요 |
| 진입 화면 예시 값 | 프로토타입은 데모라 "나다운 일로…"·리서치/제작/피드백이 채워져 있어요 | 실제 앱은 빈 칸 + 예시는 placeholder. 카테고리는 빈 칸 3개, 34/33/33으로 시작 |
| 키워드 자동 분류 코드 | 프로토타입 안에 있지만 쓰이지 않아요 | 원페이저대로 넣지 않아요 |

## 계산 (`lib/pyramid.ts`, 테스트로 고정)

| 지표 | 규칙 |
| --- | --- |
| 카테고리 시간 | 기간 안 그 카테고리 할 일 minutes 합. 체크 여부 상관없음 |
| 실제 비율 | 카테고리 시간 ÷ 기간 전체 시간(기타 포함), 정수 %, 합 100(최대 나머지 방식) |
| 치우침 | 실제 − 정한 ≥ +15 → 많음, ≤ −15 → 부족, 그 사이 "괜찮음 (±n%)". 기타는 판정 없음 |
| 판정 문장 | "A·B에 많이 썼고 C에 덜 썼어요." / "치우침 없이 정한 비율 가까이 쓰고 있어요." |
| 비율 조정안 | 카테고리마다 (정한 + 실제) ÷ 2를 합 100으로 다시 맞춤(최대 나머지 방식) |
| 주 평균 시간 | 4주 전체 시간 ÷ 시간이 적힌 날 수 × 7 |
| 시간 옮기기안 | 치우친 카테고리마다 \|차이\|% × 주 평균 시간, 30분 단위 반올림. 부족이면 "A 주 n시간 더", 많음이면 "A 주 n시간 줄이기". 0분이면 뺌 |
| 새 카테고리 권유 | 지난주까지 4주 기타 시간 ≥ 120분, 카테고리 < 5 |
