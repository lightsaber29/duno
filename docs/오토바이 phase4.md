| 항목 | 내용 |
|---|---|
| 작성일 | 2026-10-16 |
| 작성 | PM |
| 대상 | 개발 담당 |
| 화면 예시 | Duno 두 번째 버전 시각화 (https://claude.ai/artifact/H8NqLBemXDXi5Jn7WytCxa) |

## 1. 개요

두 번째 버전은 지금의 날짜별 투두에 핵심목표, 카테고리, 할 일별 기록 시간을 추가한다. 사용자는 계획한 카테고리 비율과 실제 기록 비율의 차이를 확인한다.

문서 규칙은 다음과 같다.

- 화면 구성, 레이아웃, 디자인, 데이터 구조, 알림 구현 방식은 개발 담당이 정한다.
- 화면 문구는 반말이다. 문서에 적은 문구는 예시다.
- "(확인 중)"이 붙은 요구사항은 현재 내용대로 구현한다. PM 확인 뒤 바뀔 수 있다.
- "(예시)"가 붙은 내용은 형태를 보여 주기 위한 것이다. 형태는 개발 담당이 정한다.
- 8절의 미정 사항은 적힌 임시 처리대로 구현한다. 임시 처리는 PM 확인 전이다.

### 1.1 지금 있는 기능

| 화면 | 현재 동작 |
|---|---|
| 로그인 | Google 로그인 |
| 메인 | 상단바(주 범위, 지난주와 다음 주 이동), 주간 목표 한 줄과 완료율 배지, 월~일 달성 링, 일간 목록, 할 일 입력. 지난주 이전 날짜는 읽기 전용 |
| 주간 마감 | 주가 바뀐 뒤 앱을 처음 열 때 표시. 1단계는 지난주 목표, 완료율, 달성 링, 잘된 점과 아쉬운 점. 2단계는 이번 주 목표, 지난주 못 끝낸 일 가져오기 |

## 2. 용어

| 용어 | 정의 |
|---|---|
| 핵심목표 | 여러 항목을 쌓아서 이뤄야 할 일. 한 줄로 적는다 |
| 카테고리 | 핵심목표를 위해 시간을 쓰는 영역. 최대 5개 |
| 기타 | 생활과 쉼처럼 핵심목표를 이루는 데 필요하지만 카테고리에 속하지 않는 일. 카테고리 개수에 포함하지 않는다 |
| 핵심목표 비율 | 진입에서 정하는 카테고리별 비율(정수 %). 합계 100% |
| 주간 목표 | 주마다 적는 목표 한 줄 |
| 주간 비율 | 주마다 정하는 카테고리별 비율(정수 %). 합계 100% |
| 주간 목표 시간 | 한 주에 핵심목표를 위해 쓸 시간. 기타 시간도 포함한다 |
| 기록 시간 | 저녁 회고에서 할 일마다 입력한 시간 |
| 실제 비율 | 기간 안에서 카테고리의 기록 시간이 전체 기록 시간에서 차지하는 비율 |
| 편향 | 실제 비율과 기준 비율(핵심목표 비율 또는 주간 비율)의 차이 |
| 피라미드 구조 | 핵심목표 → 주간 목표 → 카테고리 → 할 일로 이어지는 기록 구조 |
| 비율 스냅샷 | 카테고리를 추가하거나 삭제한 시점의 핵심목표 비율을 저장한 기록 |

## 3. 우선순위

MoSCoW 방식으로 나눈다. Must는 반드시 필요한 기능, Should는 필요한 기능, Could는 다음 버전 후보, Won't는 제외 기능이다. 이번 버전은 Must와 Should를 구현한다.

| 등급 | 기능 | 연결되는 기존 화면 | 요구사항 |
|---|---|---|---|
| Must | 진입 | 로그인 다음, 메인 이전 | 4.1 |
| Must | 할 일 + 카테고리 | 메인의 할 일 입력, 일간 목록 | 4.2 |
| Must | 저녁 회고 (메인 회고 버튼 포함) | 메인 | 4.3 |
| Must | 편향 보기 (핵심목표 비율 기준) | 메인 | 4.4 |
| Should | 할 일 입력 권유 | 메인의 할 일 입력 | 4.5 |
| Should | 회고 알림 | 저녁 회고 | 4.6 |
| Should | 주간 목표 + 주간 비율 | 메인의 주간 목표 | 4.7 |
| Should | 주간 마감 수정 | 기존 주간 마감 | 4.8 |

Could (다음 버전 후보)

- 편향 보기의 "최근 4주" 기간
- 편향 보기의 카테고리 상세 (기록 시간, 주별 시간, 할 일 목록)
- 저녁 회고의 목록 밖 할 일 추가
- 저녁 회고의 한 줄 회고
- 지난 날짜 회고 작성

Won't (제외)

- 마감 표시
- 카테고리 자동 분류, AI 그룹핑, AI 추천
- 타이머, 시간대별 일정
- 주간 목표 완료율

## 4. 요구사항

### 4.1 진입

목적
- 핵심목표: 이루고 싶은 일을 적고 그것을 기준으로 기록을 연결하는 앵커다.
- 카테고리: 나중에 AI가 카테고리와 피라미드 구조를 바탕으로 그룹핑할 때 기준이 된다.
- 핵심목표 비율: 기준점을 명확히 하고 시간을 어느 정도 써야 하는지 명확히 한다.
- 주간 목표 시간: 편향이 있더라도 그 주에 일을 했는지 판단하는 기준이다.

| ID | 요구사항 |
|---|---|
| ON-1 | 핵심목표가 없는 사용자는 진입을 완료해야 메인으로 이동한다. 진입은 건너뛸 수 없다 |
| ON-2 | 핵심목표를 한 줄로 입력받는다. 예: IT 회사 PM으로 취업하기 (예시) |
| ON-3 | 카테고리를 최대 5개 입력받는다 |
| ON-4 | 카테고리별 핵심목표 비율을 정수로 입력받는다. 기본값은 균등 분배다. 합계가 100%가 아니면 다음으로 진행할 수 없다 |
| ON-5 | 주간 목표 시간을 입력받는다. 입력한 값은 매주 같은 값으로 적용한다 |

### 4.2 할 일 + 카테고리

목적: 하루 동안 앱을 쓰는 흐름을 만들고 한 일을 카테고리에 연결한다. (PM 확인 전)

카테고리 수정의 의도: 카테고리를 추가하거나 삭제하면 그 시점의 핵심목표 비율을 비율 스냅샷으로 남겨 따로 볼 수 있게 한다. 삭제한 카테고리의 기록 시간은 총량에만 남기고 나중에 그룹핑할 때 따로 분류한다. 카테고리를 수정하는 화면의 위치와 등급은 정하지 않는다.

| ID | 요구사항 |
|---|---|
| TD-1 | 할 일을 추가할 때 카테고리 기본값은 기타다. 사용자가 다른 카테고리나 기타를 직접 선택할 수 있다 |
| TD-2 | 카테고리 표시 방식: 할 일 옆 라벨, 라벨을 눌러 변경 (예시) |
| TD-3 | 이전 버전에서 만든 할 일은 기타로 둔다 |
| TD-4 | 카테고리를 삭제하면 해당 카테고리의 기록 시간은 전체 기록 시간 총량에만 남는다. 편향 보기의 카테고리 목록에는 표시하지 않는다 |
| TD-5 | 카테고리를 삭제하면 삭제한 카테고리의 핵심목표 비율을 남은 카테고리에 각자의 비율대로 나눈다 |
| TD-6 | 카테고리를 추가하거나 삭제하면 변경 직전의 핵심목표 비율을 비율 스냅샷으로 저장한다 |
| TD-7 | 메인의 주간 목표 완료율 배지를 제거한다 |
| TD-8 | 날짜별 달성 링은 유지한다 |
| TD-9 | 전날 완료하지 않은 할 일은 다음 날로 옮기지 않는다 (확인 중) |
| TD-10 | 주의 시작은 월요일이다 |

### 4.3 저녁 회고

목적: 할 일마다 시간을 기록해 실제 비율을 계산할 수 있게 한다. (PM 확인 전)

| ID | 요구사항 |
|---|---|
| RV-1 | 메인에 저녁 회고로 이동하는 버튼을 둔다 |
| RV-2 | 그날의 할 일을 모두 표시하고 할 일마다 시간과 분을 숫자로 입력받는다 |
| RV-3 | 회고는 당일만 작성할 수 있다. 당일 안에는 입력한 시간을 수정할 수 있다 |
| RV-4 | 완료 체크 여부와 관계없이 입력한 시간을 계산에 포함한다 |
| RV-5 | 0분을 입력해 저장한 날도 기록한 날로 본다 |
| RV-6 | 하루 입력 시간의 합계가 24시간을 넘으면 저장할 수 없다 |

### 4.4 편향 보기

목적: 사용자가 편향을 알아차리고 편향의 반대쪽 일을 작은 단위로 하게 한다.

| ID | 요구사항 |
|---|---|
| BI-1 | 메인에서 편향 보기로 이동할 수 있다. 위치는 개발 담당이 정한다 |
| BI-2 | 핵심목표 비율과 "지금까지"의 실제 비율을 카테고리별로 비교해 표시한다 |
| BI-3 | "지금까지"는 진입한 날부터다. 핵심목표를 변경하면 변경한 날부터 다시 센다 |
| BI-4 | 편향의 절댓값이 15 이상이면 구분해 표시한다. 실제 비율이 높으면 "더", 낮으면 "덜"이다 |
| BI-5 | 편향의 절댓값이 15 미만이면 "계획대로"로 표시한다 |
| BI-6 | 기록 시간이 0이면 실제 비율 대신 핵심목표 비율만 표시한다 |
| BI-7 | 표시 문구는 "더 / 덜 / 계획대로" (예시) |

### 4.5 할 일 입력 권유

목적: 사용자는 주간 목표 때문에 덜 쓴 카테고리의 일을 하지 않는다. 권유는 주간 목표 쪽으로 쏠린 결과를 처음 목표(핵심목표 비율) 기준으로 보고 덜 쓴 카테고리를 리마인드해 할 일 하나를 실제로 실행하게 한다.

| ID | 요구사항 |
|---|---|
| NU-1 | 할 일 입력 영역에 표시한다 |
| NU-2 | 핵심목표 비율 대비 "지금까지"의 실제 비율이 15 이상 낮은 카테고리가 있을 때 표시한다. 기록 시간이 0이어도 진입 직후부터 표시한다 |
| NU-3 | 카테고리 1개와 할 일 1개를 제시한다 |
| NU-4 | 해당 카테고리의 지난 할 일 중 기록 시간이 가장 짧은 할 일을 제시한다 |
| NU-5 | 해당 카테고리에 지난 할 일이 없으면 카테고리만 제시한다 |
| NU-6 | 사용자가 닫으면 그날은 다시 표시하지 않는다 |
| NU-7 | 제시한 할 일을 누르면 오늘 할 일 목록에 추가한다 (확인 중) |
| NU-8 | 제시한 할 일이 그 주 안에 완료 체크되고 저녁 회고에 시간이 입력되면 성공으로 본다 |

문구 예시: `포트폴리오에 계획보다 시간을 덜 썼어 · [+ 케이스 스터디 목차 30분] [닫기]`

### 4.6 회고 알림

목적: 알림에서 회고 작성까지 이어지게 한다.

| ID | 요구사항 |
|---|---|
| NT-1 | 알림을 누르면 저녁 회고 화면을 연다 |
| NT-2 | 알림 시각은 저녁 9시다 (확인 중) |

### 4.7 주간 목표 + 주간 비율

목적: 주마다 어떤 일을 목표로 카테고리 비율을 정했는지 구별해서 보고 그 주를 비교하는 기준으로 쓴다.

| ID | 요구사항 |
|---|---|
| WG-1 | 주마다 주간 목표와 주간 비율을 함께 저장한다. 주간 비율의 합계는 100%다 |
| WG-2 | 편향 보기에서 "이번 주"를 선택하면 그 주의 주간 비율과 실제 비율을 비교한다 |
| WG-3 | 편향 보기에서 다른 주를 선택해 볼 수 있다 |
| WG-4 | 주간 비율은 주간 마감에서 수정한다 (확인 중) |
| WG-5 | 주간 비율을 수정하지 않은 주, 주간 마감을 건너뛰거나 열지 않은 주, 진입 직후 첫 주는 핵심목표 비율을 주간 비율로 쓴다 |

### 4.8 주간 마감 수정

목적: 사용자가 회고하고 계획이나 카테고리를 바꿀지 리마인드한다. 주간 마감이 없으면 사용자는 잊어버려서 바꾸지 않는다. 주간 마감을 거친 사용자는 그 주의 주간 목표가 달라진다. 지난주를 보고 무언가를 바꾸면 성공으로 본다.

이 절의 "그 주"는 주간 마감을 연 날이 속한 주(월요일 시작)다. "지난주"는 그 바로 앞 주다.

| ID | 요구사항 |
|---|---|
| WC-1 | 주가 바뀐 뒤 앱을 처음 열 때 표시하는 기존 동작을 유지한다 |
| WC-2 | 기존 완료율 숫자를 제거한다 |
| WC-3 | 지난주 기록 시간(기타 포함)과 주간 목표 시간을 함께 표시한다 |
| WC-4 | 지난주 기록 시간이 주간 목표 시간 이상이면 "했다"로 표시한다 |
| WC-5 | 지난주 편향을 지난주 주간 비율 기준으로 표시한다 (확인 중) |
| WC-6 | 그 주의 주간 목표를 입력하거나 수정한다 |
| WC-7 | 주간 목표 시간을 수정할 수 있다. 수정한 값은 그 주부터 적용한다 |
| WC-8 | 그 주의 주간 비율을 수정할 수 있다 (확인 중) |
| WC-9 | 카테고리를 추가, 이름 변경, 삭제할 수 있다. 삭제와 추가는 4.2의 규칙을 따른다 (확인 중) |
| WC-10 | 핵심목표 비율은 사용자가 주간 마감에서 직접 수정하지 않는다 (확인 중) |
| WC-11 | 사용자가 무언가를 바꿨는지 기록한다. 기록 방식은 개발 담당이 정한다 (확인 중) |

## 5. 계산 규칙

| 값 | 계산 |
|---|---|
| 카테고리 기록 시간 | 기간 안에서 해당 카테고리 할 일에 입력한 시간의 합 |
| 실제 비율 | 카테고리 기록 시간 ÷ 기간 안의 전체 기록 시간 × 100 |
| 편향 | 실제 비율 − 기준 비율 |
| 편향 표시 | 편향 ≥ 15이면 "더", 편향 ≤ −15이면 "덜", 그 사이는 "계획대로" |
| 주간 달성 | 그 주 전체 기록 시간(기타 포함) ≥ 주간 목표 시간이면 "했다" |
| 균등 분배 | 100을 카테고리 수로 나눈 몫을 정수로 넣는다 |

## 6. 기준 비율과 기간

| 비교 | 기준 비율 | 기간 | 등급 |
|---|---|---|---|
| 처음 목표 비교 | 핵심목표 비율 | 지금까지 (진입일 또는 핵심목표 변경일부터) | Must |
| 그 주 비교 | 주간 비율 (없으면 핵심목표 비율) | 선택한 주 | Should |
| 처음 목표 비교 | 핵심목표 비율 | 최근 4주 | Could |

## 7. 개발 담당 재량

- 카테고리 선택 방식, 비율 입력 방식
- 편향 보기로 이동하는 위치
- 화면 구성과 디자인

## 8. 미정 사항과 임시 처리

| 항목 | 관련 | 임시 처리 |
|---|---|---|
| 편향 판정에서 기타를 분모에 넣을지 | 5절, BI-2 | 지금 계산 규칙대로 분모에 포함한다 |
| 편향 기준 15의 단위 | BI-4, NU-2 | 실제 비율과 기준 비율의 차이 15 (예: 계획 30%, 실제 45%) |
| 카테고리를 추가할 때 핵심목표 비율 | TD-6 | 새 카테고리는 0%로 추가한다 |
| 할 일의 카테고리를 바꿀 때 기록 시간 | TD-2 | 기록 시간도 바꾼 카테고리로 옮긴다 |
| 핵심목표를 변경하는 곳 | BI-3 | 이번 버전에서는 변경 기능을 두지 않는다 |
| 비율 스냅샷을 보여 주는 화면 | TD-6 | 이번 버전에서는 저장만 하고 보여 주지 않는다 |
| 균등 분배 나머지 | ON-4 | 앞 카테고리부터 1씩 더한다 (예: 34, 33, 33) |
| 카테고리 최소 개수 | ON-3 | 1개 |
| 주간 목표 시간에 못 미친 주의 표시 | WC-4 | 기록 시간과 주간 목표 시간만 표시한다 |
| 핵심목표 비율로 "시간을 어느 정도 써야 하는지" 보여 주기 | 4.1 | 이번 버전에서는 비율만 보여 준다 |
| 편향 보기 화면 이름, 처음 열 때의 기간 | 4.4 | 이름은 "편향 보기", 기간은 "지금까지" |
| 권유 대상 카테고리가 여럿일 때 | NU-3 | 편향이 가장 큰 카테고리 하나 |
| 가장 짧은 할 일이 0분이거나 같은 시간이 여럿일 때 | NU-4 | 0분은 제외하고 같으면 가장 최근 할 일 |
| 권유를 닫는 범위, 추가한 뒤 다시 표시 | NU-6, NU-7 | 닫거나 추가하면 그날 권유 전체를 표시하지 않는다 |
| 알림 권한 거부, 이미 회고한 날의 알림, 알림 시각 변경 | 4.6 | 권한이 없으면 보내지 않는다. 이미 회고한 날도 보낸다. 시각은 바꿀 수 없다 |
| 편향 보기에서 고를 수 있는 주 | WG-3 | 진입한 주부터 이번 주까지 |
| 주간 마감의 요일별 달성 링, 잘된 점과 아쉬운 점, 지난주 못 끝낸 일 가져오기 | 4.8 | 기존 동작을 유지한다 |
| 정보 수집 동의 화면, 쉬는 날 기록, 연속 기록 일수 | | 넣지 않는다 |
| 화면에 "편향"이라는 용어를 쓸지 | | 화면 이름 외에는 "더 / 덜 / 계획대로"로 표시한다 |
