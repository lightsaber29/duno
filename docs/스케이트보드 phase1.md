# 날짜별 투두 앱 원페이저 기획안

기준일: 2026-10-15 · 첨부: `날짜별-투두앱-프로토타입.html` (브라우저로 열면 바로 눌러 볼 수 있음)

## 한 줄 요약

날짜별로 할 일을 기록하고, 핸드폰 한 화면에서 그 주와 그날을 함께 보는 투두 앱이에요. 주마다 목표를 한 줄로 적고, 주가 끝나면 완료율이 기록돼요.

- 화면: 핸드폰 세로 화면 하나에 주간(위)과 일간(아래)을 나눠서 보여 줌
- 기록 단위: 날짜별
- 목표: 주 단위로 한 줄, 주가 지나면 완료율 기록

## 화면 구성

위에서 아래로 다섯 칸이에요.

1. **상단바**: ‹ 주 범위 › (예: 10/13 – 10/19). 화살표로 지난주·다음 주로 이동
2. **주간 목표**: 텍스트 한 줄, 17px 굵게. 오른쪽에 진행 상태 배지. 누르면 바로 수정
3. **주간 줄**: 월~일 7칸. 날짜마다 그날 할 일을 얼마나 했는지 달성 링(원 그래프)으로 표시. 누르면 아래 일간 목록이 그 날짜로 바뀜
4. **일간 목록**: 고른 날짜의 할 일. 체크하면 취소선
5. **할 일 입력**: 화면 맨 아래. 할 일을 적고 추가

## 확정 사항

| 항목 | 결정 |
| --- | --- |
| 일간·주간 배치 | 상하 분할 (위 주간, 아래 일간) |
| 주간 표시 형태 | 날짜별 달성 링 |
| 어제 못한 일 | 그대로 둠 (그날 기록으로 남김, 다음 날로 넘기지 않음) |
| 주간 목표 형태 | 텍스트 한 줄, 17px 굵게 |
| 주간 목표 위치 | 상단바(주 범위) 바로 아래 |
| 완료율 기준 | 그 주 할 일 전체 중 체크한 비율 |
| 한 주 시작 요일 | 월요일 (월~일) |

## 주간 목표·완료율 규칙

- 주 단위로 목표를 한 줄 적고, 주가 끝나면 완료율을 기록해요.
- 배지 표시
  - 이번 주: "진행 중 n%" (체크할 때마다 바뀜)
  - 지난주: "완료율 n% 기록" (일요일이 지나면 고정)
  - 다음 주: "시작 전"
- 목표 문장은 30자 이내를 권장해요. 17px에서 두 줄 안에 들어가는 길이예요.

## 주간 마감 흐름

주가 끝난 뒤 앱을 처음 열 때 2단계 화면이 떠요. 지난주를 돌아보고 바로 이번 주 목표를 정하게 해서, 완료율 기록이 다음 주 계획으로 이어져요.

1. **지난주 돌아보기**: 지난주 목표, 완료율(할 일 n개 중 n개), 요일별 달성 링을 보여 줘요. 잘된 점·아쉬운 점을 한 줄씩 적어요.
2. **이번 주 목표 정하기**: 지난주 아쉬운 점을 위에 보여 줘요. 이번 주 목표를 한 줄로 적으면 상단바 아래 목표 칸에 들어가요. 지난주 못 끝낸 일 중 체크한 것만 이번 주 월요일 목록에 추가해요. "이번 주 시작"을 누르면 일반 화면으로 돌아가요.

규칙

- 회고 한 줄은 선택 입력이에요. 비워도 넘어갈 수 있어요.
- "건너뛰기"를 누르면 그 주는 완료율만 기록하고 끝나요. 다시 보여 주지 않아요.
- 지난주 못 끝낸 일은 옮기지 않고 복사해요. 지난주 완료율 기록이 바뀌지 않게 하기 위해서예요.

## 기능 범위

**이번 버전 (프로토타입에 구현됨)**

- 날짜별 할 일 추가, 체크
- 주간 줄 날짜 선택, 지난주·다음 주 이동
- 주간 목표 작성·수정, 진행 상태 배지
- 주간 마감 흐름 (돌아보기 → 이번 주 목표·가져올 일 선택)

**다음 후보 (아직 순서 미정)**

| 기능 | 하는 일 |
| --- | --- |
| 반복 할 일 | 매일·요일 반복을 정하면 해당 날짜에 자동으로 들어감 |
| 월간 추세 | 주간 완료율 4~5주를 막대로 이어 봄 |
| 알림 | 저녁에 오늘 체크, 일요일에 다음 주 목표 작성 알림 |
| 할 일 순서 바꾸기 | 길게 눌러 끌어서 이동 |

## 결정 과정

시안을 두 라운드 만들어 비교한 뒤 A′(상하 분할 + 달성 링)를 기본안으로 골랐어요. 평가는 시안 비교로만 했고, 실사용 테스트는 아직이에요.

| 라운드 | 시안 | 결과 | 이유 |
| --- | --- | --- | --- |
| 2 | A′ 상하 분할 + 달성 링 | 채택 | 일간을 가리지 않고 날짜별 달성률이 한 줄에 보임 |
| 2 | B′ 접이식 + 라벨×요일 색 칸 | 미채택 | 한 번 더 펼쳐야 하고 읽는 법을 익혀야 함 |
| 1 | A 상하 분할 + 날짜 점 | A′로 개선 | 점은 할 일 유무만 보여 줌 |
| 1 | B 반반 분할 + 막대 | B′로 개선 | 주간이 절반을 차지해 일간이 3~4개만 보임 |
| 1 | C 주간 카드 넘기기 | 탈락 | 옆으로 넘기기와 주 이동이 헷갈리고 주간 비교가 안 됨 |
