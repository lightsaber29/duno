# 자전거 phase3 개발 계획

기준일: 2026-10-16 · 기준 문서: `자전거 phase3.md`(PM 기획서, 문서 안에서는 "Duno 두 번째 버전") · 화면 예시("두 번째 버전 시각화")는 받지 못함

## 한 줄 요약

phase2 위에 **주간 목표 시간, 주간 비율, 할 일 입력 권유**를 더하고, 주간 마감을 "계획·카테고리를 바꾸는 자리"로 다시 짜요. 편향 보기(지금의 피라미드)에는 "지금까지" 기간을 넣고, 화면 문구는 반말로 바꿔요.

## 먼저 알아 둘 점: 이 문서는 phase1 기준으로 쓰였어요

기획서는 "지금의 날짜별 투두에 핵심목표, 카테고리, 할 일별 시간 기록을 추가한다"로 시작해요. **phase2에서 이미 만든 것을 모르는 상태로 쓰인 문서**예요. 그래서 요구사항을 셋으로 나눴어요.

## 검토 결과: 바로 개발 가능한가

**Must는 거의 다 되어 있고, 새로 할 일은 Should 쪽에 몰려 있어요.** 결정 8개(D1~D8)는 2026-10-16에 모두 정했어요(D4는 하지 않음, 나머지는 추천안). 개발을 시작할 수 있어요.

### 문서에 없어서 제가 정하고 갈 것 (다르면 알려 주세요)

- **주간 목표 시간 입력**: 시간 단위 숫자(0.5시간 간격, 1~100시간). 진입 기본값 20시간.
- **"했다" 기준**: 지난주 전체 기록 시간(기타 포함) ≥ 그 주 주간 목표 시간. 못 미친 주는 7절 미정이라 숫자만 보여 주고 따로 표시하지 않아요.
- **주간 목표 시간을 고치면**: 마감은 새 주가 시작된 뒤에 하니, "다음 주"는 지금 시작된 이번 주예요(WC-6 "다음 주의 주간 목표"와 같은 뜻). 이번 주부터 적용해요.
- **편향 보기 기간과 기준**: 지금까지(핵심목표 비율) · 최근 4주(핵심목표 비율, D2) · 주별(그 주의 주간 비율, D7). **처음 열 때는 "지금까지"**(Must 비교라서). "지금까지"에서는 주간 목표 칸을 숨겨요(주가 많아 길어짐).
- **편향 문구**: "n% 더" / "n% 덜" / "계획대로". 단위는 7절 미정이라 지금처럼 %. 화면에 "편향"이라는 말은 7절 미정이라 쓰지 않고, 화면 이름도 지금처럼 "피라미드".
- **편향 경계**: 15 **초과**(BI-3 "넘는", NU-2 "넘게"). 15%p 딱 맞으면 계획대로.
- **지운 카테고리**: 고르기 칩·라벨 순환·비율 입력에서 빠져요. 그 카테고리 할 일의 라벨은 이름 그대로 회색으로 보이고, 편향 계산에서는 기타처럼(정한 비율 없음) 다뤄요. 시간 총량은 그 카테고리에 남아요(TD-3, 나중 AI 묶기용).
- **권유 닫기**: 그날 다시 안 보이게 날짜별로 DB에 저장(기기를 바꿔도 같게).
- **권유로 추가한 할 일**: 표시를 남겨 두고(NU-8 성공 판단용), 화면에 성공을 따로 보여 주지는 않아요.
- **바꾼 것 기록(WC-11)**: 마감한 주 기록에 무엇을 바꿨는지(주간 목표·목표 시간·주간 비율·카테고리) 남겨요. 화면에는 안 보여요.
- **주간 마감의 요일별 달성 링, 잘된 점·아쉬운 점, 못 끝낸 일 가져오기**: 7절 "유지 여부 미정"이라 **지금 그대로** 둬요(지금은 링 없음, 나머지 둘 있음).

## 진행 순서

phase1·2처럼 단계마다 멈추고 확인받고, 단계마다 커밋해요. 2026-10-16 1~8단계 모두 끝남 (브랜치 `todo-phase3`).

1. **스키마**: `supabase/phase3.sql`. 로컬 Postgres에서 phase2 데이터 위에 실행해 보고, 사용자가 Supabase에서 실행
2. **계산**: 주간 비율·목표 시간 찾기, 편향 경계 15 초과, 주간 달성, 권유 고르기, 카테고리 지울 때 비율. 테스트
3. **반말 전환** (D3): 모든 화면 문구
4. **진입**: 주간 목표 시간 단계
5. **피라미드(편향 보기)**: 지금까지 탭, 주별 기준을 주간 비율로, 문구·경계
6. **할 일 입력 권유**
7. **주간 마감 다시 짜기**: 지난주 정리·이번 주 계획, 카테고리 추가·이름 바꾸기·지우기, 바꾼 것 기록, phase2의 A·B·기타 권유 없애기
8. **마무리**: seed를 phase3 데이터로, README, 진짜 Supabase로 확인

## 구현하며 정한 것

문서에 없거나 계획과 달라서 구현 중에 정한 것들이에요.

- 진입 3단계 안내 문구에서 "편향" 대신 "치우침"(화면에 "편향"을 쓸지는 7절 미정).
- 편향 문구에 단위 %를 붙여 "n% 더 / n% 덜 / 계획대로 (±n%)", 판정 문장은 "리서치에 계획보다 더 썼고 제작에 덜 썼어."
- 피라미드 카드 위 캡션에 기준을 밝혀요: "핵심목표 비율 vs 실제 시간" / 주별은 "주간 비율 vs 실제 시간".
- 할 일 입력 권유는 오늘을 볼 때만 보여요. 제시한 할 일을 더하면 그날 권유도 닫혀요. 카테고리만 권할 때 버튼은 "+ 제작 할 일 적기"(그 카테고리를 골라 입력 칸으로).
- 주간 마감 2단계 이름은 "지난주 정리", 3단계는 이번 주 목표·비율·목표 시간·못 끝낸 일. 지우기에는 "되돌리기", 지우거나 더하면 핵심목표 비율이 어떻게 바뀌는지 미리 보여 줘요.
- 마감 3단계 주간 비율에 "똑같이 나누기" 버튼. 합이 100이 아니거나 목표 시간이 맞지 않으면 시작할 수 없어요.
- 지운 카테고리의 못 끝낸 일은 기타로 복사해요(새 할 일이 지운 카테고리에 들어가지 않게).
- 이미 진입을 마친 계정은 주간 목표 시간이 없어요. 마감 2단계에 "목표 없음"으로 보이고, 3단계 기본값 20시간으로 정하게 돼요.
- 주간 목표 시간 찾기는 값이 빈 행(null·없음)을 건너뛰어요.
- 마감 저장은 여러 번 나눠 일어나요(카테고리·비율·주간 비율·목표·복사·마감 표시). 마감 표시 전에 끊기면 다시 뜨고 새 카테고리·복사가 겹칠 수 있어요(드문 경우라 그대로 둠, 필요하면 DB 함수로 묶기).
